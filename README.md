# Курсовая 3
    В рамках данной работы реализован скрипт получения данных о самолетах в выбранных пользователем странах 
    с дальнейшим добавлением их в локальную БД

## Установка
    1. Клонируйте репозиторий: https://github.com/romanivanov531/Coursework_3.git
    2. Установите зависимости. Указаны в файле pyproject.toml
    3. Создайте .env файл. Пример заполнениия .envconfig
## Структура проекта
    1. src/
        • class_api.py содержит класс для получения информации о салетах
        • db_class.py содержит класс для получения информации из БД
        • db_config.py содержи класс для создания БД, таблиц и их заполнения
    2. utils/    
        • planes_filter.py модуль для фильтации информации о самолетах
